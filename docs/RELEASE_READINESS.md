Normal backend `dev`/`start` still select MongoDB through [server startup](../server/server.ts) and [legacy composition](../server/app.ts). Requests reaching the retired legacy `/api/upload` namespace middleware receive 503 before parsing or provider access; existing CORS origin/preflight handling runs earlier. Cloudinary/Multer dependencies and unused legacy files remain for focused cleanup. Existing no-image auth/report/station/feeding routes remain.

The [PostgreSQL preview](../server/preview/runtime.ts) binds the API to `127.0.0.1:4001`, with frontend PostgreSQL mode at `127.0.0.1:5175`. It uses guarded synthetic storage, explicit migrations and a dedicated secret; it is not production composition. Private S3 support is opt-in. Attached images are publicly readable through short-lived signed redirects by current policy; a private bucket does not make the application audience private. Content references currently use the loopback API.

Implemented capabilities include Hebrew/RTL login and registration, public stations and feeding history, authenticated station/feeding creation, guest reports without images, report claiming/resolution, and directly loaded account-scoped assigned reports. PostgreSQL transactions and media ownership/attachment controls have integration evidence. NGO/municipal roles, dispatch/acceptance integrations, a private case tier, and sterilization workflows are not implemented.
